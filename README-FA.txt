شروع برنامه‌ریزی — نسخه 25.0

این بسته یک ارتقای مستقل از نسخه 23.4 است. تمام فایل‌ها مستقیماً در ریشه ZIP قرار دارند و پوشه داخلی ندارند.

مهم‌ترین تغییرات:
- رفع خطای نبودن تابع renderStudy که باعث شکست renderAll و همگام‌سازی می‌شد.
- تکمیل نمایش جلسات مطالعه، مجموع زمان مطالعه و امتحان‌های پیش‌رو.
- مرتب‌سازی منوی پایین در دسکتاپ و یکسان‌سازی فاصله و اندازه دکمه‌ها.
- چیدمان عمودی، هم‌راستا و فاصله‌دار دکمه‌های تنظیمات، حساب ابری و پشتیبان‌گیری.
- تکمیل ترجمه انگلیسی بخش حساب کاربری، همگام‌سازی ابری و نصب برنامه.
- بهبود جست‌وجوی سراسری با نتایج قابل انتخاب و انتقال به بخش مربوط.
- به‌روزرسانی نسخه و شناسه کش PWA برای دریافت فایل‌های جدید.

قابلیت‌هایی که از نسخه قبل حفظ و یکپارچه شده‌اند:
داشبورد و نمودارها، گزارش‌ها، گزارش ماهانه، تقویم، عادت‌ها و زنجیره تداوم، برنامه هوشمند، اولویت وظایف، یادآورها، پشتیبان‌گیری و بازیابی، قفل برنامه، مدیریت مالی، مهارت‌ها و چالش‌ها.

انتشار PWA در GitHub Pages:
1) فایل‌های ZIP را مستقیماً در ریشه مخزن Start-planning استخراج/بارگذاری کن؛ داخل پوشه جداگانه قرار نده.
2) شاخه main و پوشه /(root) را در Settings > Pages انتخاب کن.
3) آدرس سایت: https://pouyanesmaili.github.io/Start-planning/

ساخت نسخه Android:
- پیش‌نیازها: Node.js، Android Studio و Android SDK.
- در ریشه پروژه اجرا کن:
  npm install
  npm run android:add
  npm run cap:sync
  npm run android:open
- سپس در Android Studio از Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیر.
- پوشه www داخل ZIP نیست و با npm run copy:web ساخته می‌شود.

داده‌ها:
- ساختار ذخیره‌سازی IndexedDB و localStorage حفظ شده است؛ این نسخه دیتابیس محلی را پاک یا بازنشانی نمی‌کند.
- قبل از انتشار نسخه جدید، از Settings > Backup and restore یک فایل JSON پشتیبان بگیر.
- همگام‌سازی ابری همچنان دستی است و با حساب Supabase انجام می‌شود. ادغام فعلی بر اساس شناسه رکورد و زمان موجود در داده‌هاست؛ حذف رکوردها هنوز به‌صورت tombstone به دستگاه‌های دیگر منتقل نمی‌شود. برای جلوگیری از حذف ناخواسته، این نسخه تغییر مخرب در منطق حذف ابری اعمال نمی‌کند.
- کلید publishable موجود در کد، کلید عمومی کلاینت است. کلید service_role یا رمز عبور را در کد یا فایل عمومی قرار نده.

نکات تست:
- فایل planners.js با node --check بررسی شده است.
- فایل sw.js با node --check بررسی شده است.
- JSONهای package.json و manifest.json معتبرند.
- شناسه‌های HTML تکراری و مسیرهای asset محلی شکسته شناسایی نشدند.
- CSS با parser بررسی شده و خطای نحوی گزارش نشده است.
- اجرای مرورگر headless در محیط ساخت به‌دلیل توقف فرایند Chromium کامل نشد؛ بنابراین تست تعاملی واقعی روی دستگاه نهایی همچنان لازم است.
