شروع برنامه‌ریزی — نسخه ۲۳.۱ (بسته تخت، بدون پوشه‌های داخلی)

تمام فایل‌های این بسته مستقیماً کنار هم و در ریشه ZIP قرار دارند. پس از استخراج، لازم نیست وارد هیچ زیرپوشه‌ای شوید.

بخش PWA:
۱) همه فایل‌ها را مستقیماً در ریشه سایت Netlify منتشر کنید.
۲) سایت را با HTTPS باز کنید.
۳) در Android/Chrome یا کامپیوتر از گزینه Install app استفاده کنید.
۴) در iPhone/iPad با Safari گزینه Share > Add to Home Screen را انتخاب کنید.

بخش APK اندروید:
این بسته شامل سورس و پیکربندی Capacitor است؛ فایل APK نهایی هنوز ساخته نشده است.
پیش‌نیازها: Node.js و Android Studio به‌همراه Android SDK.
در ترمینال، در همان مسیری که package.json قرار دارد اجرا کنید:
  npm install
  npm run android:add
  npm run cap:sync
  npm run android:open
سپس در Android Studio از Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی APK بگیرید.

توجه: پوشه www در فایل ZIP وجود ندارد؛ دستور npm run copy:web آن را هنگام آماده‌سازی APK به‌صورت خودکار می‌سازد.

اطلاعات PWA و APK به‌صورت خودکار مشترک نیستند. قبل از جابه‌جایی بین نسخه‌ها از تنظیمات برنامه فایل پشتیبان JSON بگیرید و در نسخه دیگر بازیابی کنید.

Chart.js از CDN بارگذاری می‌شود و پس از بارگذاری موفق آنلاین در کش ذخیره خواهد شد؛ برای استفاده آفلاین از نمودارها، برنامه باید دست‌کم یک بار با اینترنت باز شده باشد.


انتشار روی GitHub Pages (مخزن Start-planning):
- همه فایل‌های این بسته را مستقیماً در ریشه مخزن Start-planning بارگذاری کن؛ داخل پوشه جداگانه قرار نده.
- در Settings > Pages، انتشار از شاخه main و پوشه /(root) را فعال کن.
- آدرس سایت: https://pouyanesmaili.github.io/Start-planning/
- این نسخه مسیرهای manifest و service worker را برای مسیر زیرپوشه‌ای GitHub Pages تنظیم کرده است.
- پس از انتشار، یک بار صفحه را با Chrome باز کن و در صورت باقی‌ماندن خطای قبلی، داده‌های سایت/کش همان آدرس را پاک کن و صفحه را دوباره بارگذاری کن.
